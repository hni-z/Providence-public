PRIVACY AND DATA

Your data in Providence

Providence connects your requests to computers you choose. This page explains what information is used, where it goes, and the controls available to you.

Updated October 2, 2026

What Providence keeps

Your account name, passkey public credentials, sign-in sessions, device registrations and settings are stored on the Providence server. Your biometric information and device PIN are not sent to Providence.

Providence also stores conversation history, task requests and results, transcription records, and files returned through its artifact service. Connection and request metadata can appear in operational logs.

Your OpenAI API key is entered privately during terminal setup and stored encrypted on the server. It is used to make requests for your account and is not returned to the browser. This is server-side storage; the Providence server must be trusted with that key.

AI processing

To answer and carry out requests, Providence sends messages, relevant task context, tool results and voice audio to OpenAI. Depending on a task, context or results can contain text, screenshots or files from a connected computer. Only submit information you are authorized to share.

The hosted version asks you to allow OpenAI processing before your first AI request. Your connected computers also use their own Codex sign-in and available tools. OpenAI API usage is billed to the supplied API project, separately from a ChatGPT subscription.

Provider processing and retention are governed by your OpenAI account settings and OpenAI’s data controls. Disabling API response storage is not a guarantee that a provider retains no data.

Voice

Audio and transcripts are processed between your device, Providence and OpenAI. Live voice uses a real-time connection; recorded voice is uploaded for transcription. Spoken replies are AI-generated.

Recording starts when you use the voice control and allow microphone access. Ending voice or leaving the active page stops local capture. Work already submitted can continue independently; use its Stop control to request cancellation.

Computer access

A computer connects only after its setup is authorized. Full access can allow files, terminal commands, browsers and desktop apps through the tools available on that computer. Operating-system and tool permissions still apply.

Providence’s server authenticates users and routes commands. OpenAI’s security does not replace Providence’s own access controls, and AI can make mistakes. Verify important results.

Remove a computer in Devices to revoke its Providence connection, and use the companion’s uninstall command to remove the local installation. Removing an API key alone does not revoke separate device credentials.

Your controls

  • Clear all chats removes Providence’s conversation history and hosted conversation context while keeping your account and connected devices.
  • Sign out everywhere and stop work revokes account sign-ins and begins stopping hosted work.
  • Remove saved key removes the key from active Providence account storage. Revoke it at OpenAI too if it may have been exposed.
  • Delete account revokes access and removes active hosted account data, including saved credentials and returned files. The interface reports if cleanup is still pending.

These controls cannot undo actions already performed or delete records held by OpenAI or applications on your computers. Provider retention and any independent server backups are separate from active Providence account data.
