# iPhone Mirroring adapter

This directory specifies a possible route from a registered Mac worker to its paired iPhone through Apple's iPhone Mirroring app. The contract is not proof that a physical phone can currently be controlled.

Before enabling execution, verify the intended Mac and phone, the current Mirroring connection, tool permissions, and an actual harmless phone interaction. A connected device or simulator alone does not establish that capability. Keep any verification screenshots and device metadata private.

See [the adapter contract](CONTRACT.md) and [desktop phone routing](../coordinator/docs/DESKTOP_PHONE.md).
